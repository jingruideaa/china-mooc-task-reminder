# 故障排查

| 现象 | 检查方法 |
| --- | --- |
| 扩展无法加载，缺少 `bridge_config.js` | 执行 setup，然后重新加载 `extension` 文件夹。 |
| 提示 MOOC 登录失效 | 在平时使用的浏览器配置中登录 MOOC，再点击立即检查。 |
| 提示邮件服务连接失败 | 确认 `npm start` 或 Windows 任务正在运行，本机端口为 8765。 |
| 服务提示端口被占用 | 检查是否仍有另一个目录的邮件桥接服务，先停止旧实例。 |
| 配置令牌不匹配 | 在同一份项目中重新执行 setup，并重新加载该目录的扩展；不要混用两个目录的设置。 |
| SMTP 发信失败 | 检查 `.local/config.json`、邮箱 SMTP 开关、网络和授权码；使用当前 Windows 用户重新保存凭据。 |
| QQ 邮件未出现在收件箱 | 先看扩展是否显示发送成功，再检查邮箱的垃圾邮件与过滤规则；SMTP 接受不保证最终送达收件箱。 |
| Windows 登录后没有服务 | 检查任务计划程序中的 `ChinaMOOC-MailBridge`；系统禁用 Windows Script Host 时，可先用 `npm start` 手动启动。 |
| 每日邮件延迟 | 确认检查时间前后电脑和浏览器运行并联网；睡眠或关机期间不会准点检查。 |
| 完成了任务但仍提示待核实 | 打开网站核对状态；不同课程版式可能需要更新读取逻辑。待核实不等于未完成。 |
| 考试区域无法识别 | 报告会保留未能确认的说明，避免解释为没有考试；可提交脱敏的页面结构帮助修复。 |

扩展面板中可以展开完整报告。本机服务状态位于 `.local/bridge-status.json`，报告和发信回执位于 `.local/reports/`。这些文件可能包含个人邮箱、课程和任务信息，排错时只分享经过人工脱敏的片段。

本项目不需要浏览器远程调试端口、复制 Cookie、账号密码登录脚本或单独的 MOOC 浏览器资料目录。
